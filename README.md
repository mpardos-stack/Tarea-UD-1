# Mi Proyecto Web

Proyecto web sencillo para aprender Git y GitHub. Incluye una página HTML con navegación interna y un formulario de contacto sin conexión a un servicio de envío.

## Tabla de contenido

- [Instalación](#instalación)
- [Estructura](#estructura)
- [Mejoras implementadas](#mejoras-implementadas)
- [Uso](#uso)

## Instalación

Clona el repositorio y abre `index.html` directamente en un navegador web. No se necesitan dependencias.

## Estructura

- `index.html`: página principal del proyecto.
- `.gitignore`: excluye la configuración local de Visual Studio Code y archivos del sistema operativo.
- `README.md`: documentación del proyecto.

## Mejoras implementadas

- Menú de navegación con enlaces a las secciones Inicio y Contacto.
- Formulario de contacto con campos de nombre, correo electrónico y mensaje.

## Uso

Selecciona Inicio o Contacto en el menú para desplazarte a esa sección. El formulario es únicamente estructural y no envía mensajes.
